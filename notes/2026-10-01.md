题目3：转化成小写字母
![题目截图](../images/2026-10-01_003.png)
``` Go
func toLoewrCase(s string) string{
    b := []byte(s)
    for i := range(b){
        if b[i] >= 'A' && b[i] <= 'Z'{
            b[i] += 32
        }
    }
    return string(b)
}
```
> 可以使用标准库"strings",调用 ToUpper 代码更简洁
``` python
class Soution:
    def toLowerCase(self, s: str) -> str:
        b = list(s)
        for i in range(len(b)):
            if 'A' <= b[i] <= 'Z':
                b[i] = chr(ord(b[i]) + 32)
        return ''.join(b)
```
> 使用内置函数 lower 代码更简洁

``` GO
func addGigits(num int) int {
    if num == 0{
        return 0
    }
    if num % 9 == 0{
        return  9
    }
    return num % 9
}
```
``` python
class Solution:
    def addGigits(self, num: int) -> int:
        if num == 0:
            return 0
        return 9 if num % 9 == 9 else num % 9
```
