2. 在关于**3的幂**的解法，我依旧采用了循环解法,观察官方解法，更为简洁一点
> 循环解法
``` python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        if n <= 0:
            return False
        while n%3 ==0:
            n = n //3
        return n == 1
```
> 官方解法
``` python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        while n and n%3 == 0:
            n /= 3
        return n == 1
```
